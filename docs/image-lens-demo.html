REFERENCE 01 / 几何静物海报千寻助手图片反推体验
01 / CONFIGURE

先连接你的视觉模型

点击插件 → 图片反推设置，填写 API Key、模型和接口地址。

02 / EXPLORE

图片、背景或画面区域

点击图片千寻图标并选择分析，或使用 Alt ⇧ S 框选任意区域。

03 / CREATE

拆解风格，再开始创作

编辑中英文提示词，查看主体、构图、光线等结构，一键复制。
