## 安装和使用

1. 在项目根目录运行 `pnpm build`。
2. 在 Chrome 的 `chrome://extensions/` 开启开发者模式，加载 `output/chrome-mv3`。
3. 点击插件弹窗右上角的设置按钮，使用 BOFT.AI 登录；也可展开「使用自己的 API Key」，配置 Gemini 或支持视觉输入的 OpenAI 兼容接口。模型名以你的服务商实际可用名称为准。
4. 刷新一个普通 HTTP/HTTPS 网页，鼠标停在图片上，点击出现的千寻图标即可识别；也可右键选择「图透镜：识别图片」。
5. 区域框选：在插件弹窗点击「区域框选」，或按 `Alt+Shift+S`（Mac 为 `⌥⇧S`），拖动选区识别。
6. 在面板中编辑并复制提示词、切换中英文；「更多」菜单可重新识别或切换精简/完整提示词；展开「结构」可逐项复制。生图默认共用识图连接，仅需选择支持图片输出的模型；也可在「高级」中启用独立连接。
7. 在小红书、抖音、快手和 B站上，原有作者、作品、评论导出入口仍在同一插件弹窗。

## 权限和数据

- 图透镜在普通 HTTP/HTTPS 页面工作，因此使用 `<all_urls>` 主机权限读取用户选中的图片，并支持 `captureVisibleTab` 截图回退；脚本仅匹配 HTTP/HTTPS 页面，不注入浏览器内部页面。
- `storage` 用于本地保存模型配置，`contextMenus` 用于右键菜单的「识别图片」和「区域框选」。
- API Key 仅保存于当前插件的本地 Chrome storage；只有主动分析或生图时才调用配置的服务商。
- 图片和框选截图会发送给所选模型服务商；详见分发包 `image-lens/PRIVACY.md`。采集功能仍按项目原隐私政策处理数据。
- 独立 ImageLens 与 OPENSEEK 属于不同扩展 ID，配置不会自动共享；需要在千寻助手内重新填写。

## 适配范围

- 一个 WXT manifest、一个 service worker、一个工具栏 popup；没有嵌套安装第二个扩展。
- 上游后台和页面脚本通过显式初始化接入 WXT；后台及 content 消息只响应自己的类型，避免影响采集通道。
- 生成图片查看页迁移到 `image-lens/viewer.html`，设置页统一注册为插件 options_page。
- 核心识图、提示词结构和模型接口沿用上游实现；上游原始源码下载在 `/tmp/openseek-imagelens-upstream-20261031`。

## 本地体验页

在项目根目录运行 `python3 -m http.server 43119 --bind 127.0.0.1 --directory docs`，打开 `http://127.0.0.1:43119/image-lens-demo.html`。体验页提供一张本地参考图，不包含模拟识图结果，连接 AI 服务后才能真实识别。

## BOFT.AI OAuth 与统一配置

- 登录入口在图透镜设置页顶部。使用 `chrome.identity.launchWebAuthFlow`、PKCE S256、随机 state 和严格回调匹配，动态注册当前扩展的 HTTPS 回调；无需本机守护进程。
- 授权范围为 `identity:read auto_keys:issue`。验证账号后签发当前 OAuth 客户端绑定的 AUTO Key，并撤销本次临时 OAuth token。
- OAuth 成功后识图、生图都切换到 BOFT.AI；原 Gemini/OpenAI 配置保留。手动 BOFT API Key 是两种能力共用的独立配置。
- BOFT API 地址固定为 `https://api-direct.boft.ai/v1`。Gemini 生图切换到同站点 `/v1beta`，通过 Bearer 验证；GPT 图片模型使用 OpenAI 图片协议。
- 凭据和账号信息仅保存在插件本地 storage；网页只接收显示偏好，不能读取凭据或发起授权设置变更。
- 「断开连接」只清除本机 OAuth 凭据。服务端密钥可在 BOFT 账号管理中撤销；丢失本地密钥后的再次授权只恢复当前 OAuth 客户端绑定的密钥。
- 捐赠组件及付款素材已移除，产品署名为 LIBERSEEK。MIT 文件保留原始版权声明。

## 精简设置页

- 原识图、生图、通用、关于四个分页合并为单页：顶部是「AI 连接」，其次是「偏好」，其余收进一个「高级」折叠。
- 同一服务商、密钥和地址只需配置一次。BOFT.AI 登录或本机 API Key 同时供识图和生图使用，固定接口地址不再展示。
- 需要不同接口时，在「高级 → 模型」启用「生图使用独立连接」；旧版中不同的服务商、密钥或地址会自动保持独立。
- 旧配置首次打开按连接是否一致判断共用方式，读取页面不会合并或覆盖旧密钥；用户后续选择共用/独立会单独保存在本机。
- 图片入口、自动识别、中文提示词与生图开关放在「偏好」；模型、识图提示词与界面语言在「高级」；版本、文档、反馈与隐私链接在页脚。配置继续自动保存。

## 自定义识图提示词

在「图透镜设置」展开「高级」，在「识图提示词」中可直接修改识图指令，例如指定商品材质、布光、构图、描述风格和详略。默认显示内置完整指令，支持中文或英文修改，最多 8000 个字符。

- 编辑后自动保存到本机，下次识图或重新识图时生效；切换 Gemini、OpenAI 兼容服务或 BOFT.AI 时共用此配置。
- 点击「恢复默认」或清空内容，会使用内置指令。原有安装未配置此项时也继续使用内置指令。
- JSON 返回结构、九维结构字段和中英文开关由插件统一维护，以兼容现有面板、复制和生图流程。
- 自定义指令随识图请求发送给所选服务商；普通网页内容脚本不能读取或修改这项配置。

## 统一体验（2026-11-01）

- 图片上的千寻图标在鼠标停留约 0.3 秒后淡入，点击直接打开面板；面板打开时不再重复显示这张图片的图标。「偏好」中可关闭图片入口。
- 面板每个状态只给一个主操作：未连接时「前往设置」，未自动识别时「识别图片」，失败时「重试」。复制结果在按钮上显示「已复制」；重新识别、精简/完整和设置收进「更多」菜单；九维结构改为可展开的逐项复制列表。
- 面板、插件弹窗、设置页和结果页使用同一套浅色/深色配色，跟随系统；紫色只用于主操作。
- 名称统一：功能叫「图透镜」，操作叫「识别图片」「区域框选」，入口叫「设置」。中英文文案合并为 `src/integrations/image-lens/i18n.js` 一份，构建时复制到 `image-lens/i18n.js`。
- 插件弹窗：「区域框选」一行显示当前系统的实际快捷键；当前平台的批量导出平铺展示，打开对话框后弹窗自动关闭，页面脚本不可用时提示刷新；浏览器内部页面上说明不可用的原因。
- 右键菜单每处只显示一项图透镜入口：页面、图片、链接和视频上是「识别图片」，会找透明遮罩下的图片、CSS 背景图和 canvas，找不到时转为区域框选；选中文字时是「区域框选」。
- 社媒页面菜单统一为「导出…」；B站视频页「导出视频数据」直接开始，不再弹出表单；请求间隔收进「高级」；导出进度卡只保留一个主操作。
- 设置页顶部是 BOFT.AI 登录，「使用自己的 API Key」作为次要入口；常用开关在前，模型、识图提示词和界面语言收进「高级」。
