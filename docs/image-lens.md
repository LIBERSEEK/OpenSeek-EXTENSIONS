整合自 https://github.com/kevinchin12/ImageLens ，版本 1.1.1，提交 `9af6d65b28673936260899852d6de678398520d3`。

## 安装和使用

1. 在项目根目录运行 `pnpm build`。
2. 在 Chrome 的 `chrome://extensions/` 开启开发者模式，加载 `output/chrome-mv3`。
3. 点击千寻图标，选择「图片反推设置」，配置 Gemini 或支持视觉输入的 OpenAI 兼容接口。模型名以你的服务商实际可用名称为准。
4. 刷新一个普通 HTTP/HTTPS 网页，将鼠标移到图片上，点击千寻图标后选择「分析图片并生成提示词」，或右键选择图片分析。
5. 也可以从插件首页点击「框选图片区域」，或使用 `Alt+Shift+S`，拖动选区分析。
6. 在浮层中切换中英文、精简/完整提示词，查看九维结构，编辑并复制。生图默认共用识图连接，仅需选择支持图片输出的模型；也可展开独立连接。
7. 在小红书、抖音和快手上，原有作者、作品、评论采集入口仍在同一插件首页。

## 权限和数据

- 图片反推在普通 HTTP/HTTPS 页面工作，因此使用 `<all_urls>` 主机权限读取用户选中的图片，并支持 `captureVisibleTab` 截图回退；脚本仅匹配 HTTP/HTTPS 页面，不注入浏览器内部页面。
- `storage` 用于本地保存模型配置，`contextMenus` 用于图片分析和框选菜单。
- API Key 仅保存于当前插件的本地 Chrome storage；只有主动分析或生图时才调用配置的服务商。
- 图片和框选截图会发送给所选模型服务商；详见分发包 `image-lens/PRIVACY.md`。采集功能仍按项目原隐私政策处理数据。
- 独立 ImageLens 与 OPENSEEK 属于不同扩展 ID，配置不会自动共享；需要在千寻助手内重新填写。

## 适配范围

- 一个 WXT manifest、一个 service worker、一个工具栏 popup；没有嵌套安装第二个扩展。
- 上游后台和页面脚本通过显式初始化接入 WXT；后台及 content 消息只响应自己的类型，避免影响采集通道。
- 生成图片查看页迁移到 `image-lens/viewer.html`，设置页统一注册为插件 options_page。
- 核心识图、提示词结构和模型接口沿用上游实现；上游原始源码下载在 `/tmp/openseek-imagelens-upstream-20261031`。

## 本地体验页

在项目根目录运行 `python3 -m http.server 43119 --bind 127.0.0.1 --directory docs`，打开 `http://127.0.0.1:43119/image-lens-demo.html`。体验页提供一张本地参考图，不包含模拟识图结果，需配置 API 才能真实反推。

## BOFT.AI OAuth 与统一配置

- 登录入口在图片反推设置页。使用 `chrome.identity.launchWebAuthFlow`、PKCE S256、随机 state 和严格回调匹配，动态注册当前扩展的 HTTPS 回调；无需本机守护进程。
- 授权范围为 `identity:read auto_keys:issue`。验证账号后签发当前 OAuth 客户端绑定的 AUTO Key，并撤销本次临时 OAuth token。
- OAuth 成功后识图、生图都切换到 BOFT.AI；原 Gemini/OpenAI 配置保留。手动 BOFT API Key 是两种能力共用的独立配置。
- BOFT API 地址固定为 `https://api-direct.boft.ai/v1`。Gemini 生图切换到同站点 `/v1beta`，通过 Bearer 验证；GPT 图片模型使用 OpenAI 图片协议。
- 凭据和账号信息仅保存在插件本地 storage；网页只接收显示偏好，不能读取凭据或发起授权设置变更。
- 「断开连接」只清除本机 OAuth 凭据。服务端密钥可在 BOFT 账号管理中撤销；丢失本地密钥后的再次授权只恢复当前 OAuth 客户端绑定的密钥。
- 捐赠组件及付款素材已移除，产品署名为 LIBERSEEK。MIT 文件保留原始版权声明。

## 精简设置页

- 原识图、生图、通用、关于四个分页合并为单页，主要配置集中在「AI 连接」和「模型」。
- 同一服务商、密钥和地址只需配置一次。BOFT.AI 登录或本机 API Key 同时供识图和生图使用，固定接口地址不再展示。
- 需要不同接口时，展开「生图连接」并启用「使用独立连接」；旧版中不同的服务商、密钥或地址会自动保持独立。
- 旧配置首次打开按连接是否一致判断共用方式，读取页面不会合并或覆盖旧密钥；用户后续选择共用/独立会单独保存在本机。
- 自动识图、中文提示词与界面语言合并到「使用偏好」；自定义地址、关于和隐私默认折叠。配置继续自动保存。

## 自定义识图提示词

在「图透镜设置」展开「识图提示词」，可直接修改识图指令，例如指定商品材质、布光、构图、描述风格和详略。默认显示内置完整指令，支持中文或英文修改，最多 8000 个字符。

- 编辑后自动保存到本机，下次识图或重新识图时生效；切换 Gemini、OpenAI 兼容服务或 BOFT.AI 时共用此配置。
- 点击「恢复默认」或清空内容，会使用内置指令。原有安装未配置此项时也继续使用内置指令。
- JSON 返回结构、九维结构字段和中英文开关由插件统一维护，以兼容现有面板、复制和生图流程。
- 自定义指令随识图请求发送给所选服务商；普通网页内容脚本不能读取或修改这项配置。
